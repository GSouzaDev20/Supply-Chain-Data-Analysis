# End-to-End Supply Chain Data Pipeline

A comprehensive Data Engineering project focused on building a scalable data pipeline to ingest, clean, model, and analyze global supply chain logistics data.

---

## 📌 Project Overview

Supply chain operations generate massive amounts of messy, unstructured data. Delays, high shipping costs, and inventory imbalances directly impact business profitability. 

The goal of this project is to simulate a production-ready data pipeline. It processes a complex logistics dataset to track carrier performance, identify operational bottlenecks, and optimize transit lead times.

---

## 🛠️ Tech Stack & Architecture

This project implements a phased data architecture to showcase modern engineering practices:

*   **Ingestion & Storage:** SQL (PostgreSQL / SQLite) for relational data management.
*   **Data Processing (ETL):** Python (Pandas, NumPy) for data cleansing and feature engineering.
*   **Data Modeling:** Dimensional Modeling (Star Schema) for analytical performance.
*   **Business Intelligence:** Power BI for interactive KPI dashboards.

---

## 🚀 Pipeline Roadmap

* Data treatment using Pandas and creating the database using sqlite3
* Creating tables using SQL in a Star Scheme
